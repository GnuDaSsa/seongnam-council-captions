# 회의 보고에서 ‘갈음’과 ‘가름’ 구별

성남시의회 과거 회의록에 쓰인 ‘유인물로 갈음’은 자료가 설명을 대신한다는 뜻이다. ‘기업의 성패를 가름하는’은 결과를 가른다는 뜻이다. 이 두 용례를 기준으로, 전사된 문장에서 자료·서면·유인물이 바로 앞에 오고 보고를 대신한다는 종결 표현이 이어질 때만 자막 표기를 고쳤다. ‘두 사업의 우열을 자료로 가름하겠습니다’처럼 자료를 근거로 구별한다는 뜻도 검사한다. 같은 문장 앞쪽에서 우열·진위·승패 등의 판별 대상을 발견하면 ‘가름’을 보존한다.

경제환경위의 ‘식물으로 가름하겠습니다’는 앞말도 불명확해 그대로 두었다. 이 표는 전사 후 표기 교정 결과다. 해당 회의의 공식 회의록·원음과 대조한 음성 모델 정확도는 별도로 측정해야 한다. 기존 10월 7일의 과거 평가 발췌에서는 두 단어가 나타나지 않았다. 생중계, 초안, 파일 재처리에서 인식 원문과 담당자 편집을 보존하는 회귀 검사를 두었다. [구간 식별자와 예문](../tools/garum_public_fixture.json) · [회귀 검사](../tools/test_korean_corrections.cjs)
