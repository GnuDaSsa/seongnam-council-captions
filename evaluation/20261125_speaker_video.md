## 재현 도구

[video_nameplate_ocr.ps1](../tools/video_nameplate_ocr.ps1)은 **이미 로컬에 있는 정지 이미지**만 읽으며 네트워크 호출이나 이미지 저장을 하지 않는다. 전체 명부를 호출자가 전달한다. 한국어 OCR 각 줄에서 한글 이름이 공백을 제외하고 완전히 일치하는 경우만 세고, 명부 일치가 정확히 한 명이면 `unconfirmed_visible_text`로, 여러 명·직위만 검출·무검출이면 `abstain`으로 반환한다. 명부 밖의 이름이나 OCR이 놓친 다른 이름까지 배제하는 것은 아니다. 이름 전후가 다른 한글과 붙은 부분 문자열도 제외한다. 시각과 URL은 호출자 입력이며 도구가 원본을 검증하지 않는다. 사람이 영상과 음성을 확인하기 전까지 시스템은 이 후보를 발언자로 입력하거나 확정해서는 안 된다.

```powershell
$members = @('안광환','장일남','김옥수','서은경','정봉규','정연화','조우현')
& .\tools\video_nameplate_ocr.ps1 `
  -ImagePath 'C:\path\to\still.jpg' -Members $members `
  -VideoUrl 'https://cast.sncouncil.go.kr/vod/vod_view.jsp?pk_vod_no=5483' `
  -VideoSeconds 1872
```

오늘 생중계는 `-VideoSeconds`를 생략하고 `-CapturedAt '2026-11-25T15:53:25+09:00'`을 전달할 수 있다. 운영체제에 한국어 OCR 언어가 없으면 실패를 알린다. 정상 상황 검증: 실제 생방송 전체 화면에서는 김옥수 후보 1명, 명패 영역만 크롭한 `과장` 화면에서는 후보 없음, VOD 1872초에서는 후보 없음이었다. 별도로 생성한 합성 화면 `김옥수 정연화`에서는 두 이름을 모두 검출하여 후보 없음(보류)이었다. 스틸 이미지는 저장소에 포함하지 않는다.

## 공개 HLS 오디오 스트림 확인

2026-11-25에 이 문서의 5483 VOD와 2853 경제환경위 생방송에 대해 공개 HLS 매니페스트와 `ffprobe -v error -show_entries stream=index,codec_type,codec_name,channels,channel_layout:stream_tags -of json <HLS URL>`을 읽었다. 두 매니페스트에서 확인된 변형 스트림은 각 1개이고 별도의 `EXT-X-MEDIA` 오디오 트랙 선언은 없었다. `ffprobe`가 노출한 각 스트림은 `timed_id3` 데이터 1개, H.264 비디오 1개, AAC 오디오 1개였다. AAC는 두 경우 모두 2채널 `stereo`였고, 노출된 오디오 태그는 `variant_bitrate`뿐이었다. VOD 조회값은 3572442, 생방송 조회값은 690397이며 생방송 매니페스트의 대역폭 값은 조회 시점에 따라 달라질 수 있다.

이 메타데이터에서는 좌석 번호, 개별 마이크 ID 또는 채널별 화자 식별 태그를 확인하지 못했다. 스테레오의 좌우 채널이 무엇을 담는지는 이 검사로 알 수 없으며, 모든 마이크가 혼합됐다고도 단정할 수 없다. 단일 오디오 스트림과 두 채널이라는 사실만으로 좌석별 분리 수집이나 발화자 식별 기능을 추론하지 않는다.

스크립트 정리 후 합성 화면 `김옥수 정연화`로 다시 실행했을 때 OCR은 두 이름을 모두 반환했고 결과는 `candidate: null`, `status: abstain`이었다. 합성 이미지는 검증 직후 삭제했다.

## 생중계에서 명패 대조하기

운영 PC는 편성표의 HLS 중계마다 60초에 한 번 화면을 읽는다. 수집 시각과 해당 위원회 명단에 일치한 이름만 서명해 사이트에 보낸다. 전체 화면에 안건 자료나 분할 화면이 나올 수 있고, 명패가 작으면 인식기가 이름을 놓친다. 16시 18분 경제환경위, 16시 20분 행정교육위·도시건설위의 화면을 한 장씩 읽은 시험에서는 세 장 모두 명단 일치가 없었다.

경제환경위 HLS에서 확인한 영상 조각은 4~6초였고 그때의 재생목록에는 절대 방송시각(`EXT-X-PROGRAM-DATE-TIME`)이 없었다. 검토 화면은 운영 PC의 수집 시각 앞뒤 15초에 걸친 자막을 나열한다. 15초는 담당자가 살펴볼 범위이며 측정한 동기화 오차 한계는 아니다. 여러 발언이 인접하면 담당자가 자막을 선택해 원영상과 대조하고 이름을 적용한다. 중단 구간에 걸친 자막이나 긴 오류 구간에는 이름을 연결하지 않는다. 이름을 확인하지 않은 채 내보내면 자동 판독한 이름은 발언자 표기에 들어가지 않는다.

운영 PC에서 아래 명령을 회의별로 한 번 실행한다. Python의 `cryptography`, FFmpeg, Windows 한국어 OCR, 기존 자막 게시용 서명 키가 필요하다. 처음 점검할 때는 `--dry-run --once`로 화면 한 장을 확인할 수 있다.

```powershell
python tools/nameplate_publisher.py --meeting-id 2853 --end-at 2026-11-25T23:59:59+09:00
```
