# 자막에 발언자를 붙이는 기준

발언자 후보는 **지금 이 말을 한 사람**을 가리킨다. 의원이 과장에게 질문하면 그 자막에 등장하는 과장은 듣는 사람이다. 자동 후보에는 판단 이유와 자막 ID를 남긴다. 회의록 초안에 실명을 기입하는 단계는 담당자의 확인 또는 직접 입력이다.

| 자막에서 확인한 사실 | 표시 |
| --- | --- |
| “조우현 위원입니다.”처럼 직접 밝힌 이름이 해당 회의 의원 명단에서 유일하고 직원과 동명이인도 없음 | 해당 의원을 후보로 표시. 영상 재생 시각만 있는 개인 자막에서도 적용 |
| 직원이 직책과 성명을 직접 밝힘 | 출처가 있는 직원 명부에서 이름과 직책을 대조. 인사 이동·대리 참석·동명이인 때문에 대응이 불분명하면 실명 보류 |
| “안녕하십니까. 환경정책과장”과 “○○○입니다.”가 둘로 끊김 | 중간 발언·겹침·수집 중단 없이 1.5초 이내에 이어지고 두 조각을 합친 자기소개가 명부와 맞으면 뒤 자막에 후보 표시. 근거에 두 자막을 모두 기록 |
| 위원장이 의원을 호명하고 다음 자막에서 질의가 이어짐 | 호명한 자막에는 호명받은 이름을 붙이지 않음. 바로 다음 자막이 충분한 길이이고 인용·개입·답변 단서가 없을 때만 낮은 신뢰도의 후보를 표시 |
| “네, 과장님”만 대답하거나, 깨진 호명 뒤에 다른 의원의 발언을 인용함 | 실명 보류. 중간 자막을 건너뛰어 호명을 연결하지 않음 |
| 질문·답변이 한 자막에 섞이거나 여러 명이 자기소개함 | 하나의 실명을 배정하지 않음. 다음 질의에서 앞선 사람의 이름을 이어 쓰려면 새 근거가 필요 |
| 생중계 명패에 한 명이 보임 | 단독 실명 근거로 쓰지 않음. 자기소개·후속 질의와 같은 사람을 가리키는지 대조. 집행부 답변에는 질의자 명패를 넘기지 않음 |

생중계·개인 자막·운영 도구는 같은 자막 판정 함수를 호출한다. 현재 편성표에 있는 회의의 누적 기록은 예전에 저장한 자동 후보도 현재 정책으로 다시 계산한다. 공식 회의록에 대조해 둔 다시보기 자막은 원래의 기록 표기를 유지한다.

## 본회의 연단에서 길게 인사할 때

의장의 “나오셔서 발언해 주시기 바랍니다” 바로 다음 자막에서 발언자가 청중에게 인사하고 지역구·직책·본인 이름으로 문장을 끝내면 두 원문을 대조한다. 부른 이름과 본인이 말한 이름이 같은 회의 명부의 한 사람과 정확하게 일치할 때 자기소개 줄에만 후보를 표시한다. 인사에 포함된 다른 의원 이름은 ‘의장님’처럼 상대를 부르는 직책과 함께 나와야 한다. 호명 자막에는 피호명자 이름을 붙이지 않는다. 두 수집 시계의 차이가 0.5초를 넘거나, 사이에 다른 자막·수집 중단이 있거나, 같은 시각의 명패가 다르면 보류한다.

호명 다음의 자기소개가 “○○○ 의원입니다. 오늘 저는…”처럼 첫 발언으로 이어질 때도 두 사람 이름과 도입부를 대조한다. 첫 문장에 나온 동 이름을 성남시 행정동 사전에서 확인하고, 이어지는 말이 다른 사람에 대한 인용이나 질문이면 이름을 보류한다. 당시 이용할 수 있는 전체 명단이 비어 있으면 직전 90일의 의회 공식 활동과 같은 대수의 당선 영상으로 대조할 수 있다. 두 근거를 자막과 함께 보관한다. 재직 기록에서 당시 발언자의 직책을 끌어오지 않는다. [성남시의회 본회의 발언](https://cast.sncouncil.go.kr/vod/vod_view.jsp?pk_vod_no=5488&position=160)

본회의를 마치는 인사말을 검토할 때는 앞서 확인한 본인 자기소개와 뒤에 들어온 사회자의 실명 송별 인사가 같은 의원인지 확인한다. 중간에 수집이 끊겼거나 발언이 겹치거나 마지막 인사가 저신뢰이면 보류한다. 5467번 9분 10초의 실제 인사말은 원래 수집에서 저신뢰로 표시돼 이름을 보완하지 않았다.

## 다시보기 개인 자막과 공식 회의록

같은 영상에 발언자와 시각을 대조해 둔 공식 회의록 구간이 있으면 새 음성인식 자막과 비교한다. 기본값은 자막 길이 12자 이상, 시간 겹침 85% 이상이다. 한글을 포함한 정규화 문자열을 두 글자와 세 글자씩 나눠 실제 발언 내용도 대조한다. 화자가 바뀌는 경계, 같은 장 전체에만 붙은 시각, 원음 재확인 표시, 회의록과 충돌하는 자기소개에서는 실명을 보류한다. 조건을 통과해도 개인 자막에는 ‘공식 회의록 대조 추정’으로 표시한다. 설정과 근거 자막 ID 기록은 [다시보기 판정 코드](../dist/vod-speaker.js)에 있다.

중간부터 재생하면 현재 인식한 문장을 그 영상에 연결된 공식 발언록 전체에서 찾는다. 영상에 공식 장 구분이 있으면 해당 시각과 겹치는 발언만 비교한다. 같은 표현을 여러 사람이 썼거나 두 사람의 말이 섞인 경우에는 이름을 보류한다. 단독으로 대조하기 어려운 문장 두 개가 1초 이내에 연속되고, 같은 사람의 같은 발언에 순서대로 대응하면 뒤 문장에 추정 이름을 표시할 수 있다. 재생 위치를 옮기면 앞선 문맥을 지운다. [대조 설정과 판정 함수](../dist/vod-transcript.js)

회의 목록 16편 중 12편에는 공식 발언 2,644건을 연결했다. 나머지 영상은 공식 영상 페이지에서 발언자와 본문을 조회한다. 원문이 없으면 자기소개 등 자막 자체에서 확인할 수 있는 단서만 쓴다. 개인 다시보기는 브라우저의 다국어 Whisper Base로 인식하며 모델을 불러오지 못하면 Tiny로 전환한다. 기기가 재생 속도를 따라가지 못하면 일부 구간을 건너뛴다.

2026년 11월 26일, 실제 영상 중간에서 추출한 8초 단위 음성을 브라우저 모델로 인식해 공식 발언과 대조했다. 5481번 08:15부터 24초에서 3개 중 2개가 최은미 총무과장, 5467번 14:05부터 24초에서 3개 중 2개가 추선미 의원, 5483번 20:00부터 30초에서 4개 중 3개가 백진규 의원 발언에 대응했다. 이는 해당 구간에서 이름을 표시한 건수다. 초 단위 화자 정답을 독립적으로 청취해 산출한 정확도는 따로 측정해야 한다. 실제 플레이어에서도 5483번 19:56으로 이동한 뒤 음성 인식을 켜 19:56과 20:12에 백진규 의원 추정 표시를 확인했다.

## 공식 회의록을 기다리는 다시보기

공식 영상과 생중계 편성의 한국 날짜, 위원회, 회차, 안건 순서가 모두 일치해야 당시 공유 자막을 연결한다. 11월 25일 행정교육위원회 영상 5554와 수집본 2852가 한 예다. 생중계 수집기의 경과 시각과 다시보기 시각은 다를 수 있어 두 시계의 숫자를 곧바로 대응시키지 않는다. 재생한 문장을 동일 회의의 실제 수집 문장과 대조한다. 모든 미확인 문장도 경쟁 후보에 포함한다. 서로 다른 곳에서 비슷하게 말했거나 한 구간에 두 사람이 섞였으면 실명을 보류한다.

선창선 의원이 자기소개하고 “공보관님”을 부른 뒤 첫 절을 “2022년인데”에서 끊은 사례가 있었다. 첫 절만 들어왔을 때는 보류한다. 같은 공보관에게 이어지는 질문이 들어오면 두 자막의 ID를 유지하면서 앞선 절과 질문에 추정 이름을 붙인다. 뒤에 나오는 공보관의 답변은 새로 판정한다. 국·과장의 직함만 확인된 경우에는 직함을 보여준다. [공식 영상 발언 구간](https://cast.sncouncil.go.kr/vod/vod_view.jsp?pk_vod_no=5554&position=6094)

지역구와 이름을 함께 밝히는 자기소개는 실제 발음대로 적힌 이름이 해당 회의 명부에 한 번만 나오는지 확인한다. 성남시의 행정동 표현을 이용해 자기소개 문형을 구분한다. 지명에 들어간 숫자·단위를 잘못 인식한 경우에도 이름은 원래 자막과 정확히 일치해야 한다. 회의 명부와 충돌하거나 화면 명패에 다른 의원 한 명이 대응하면 이 방식의 실명 표시는 보류한다. [성남시 행정구역](https://www.seongnam.go.kr/cn040104) · [제310회 제2차 본회의 발언 구간](https://cast.sncouncil.go.kr/vod/vod_view.jsp?pk_vod_no=5398&position=392)

## 같은 회의 안에서 음성 대조하기

공유 자막 생성기는 선택한 설정에 따라 실제 수집 음성을 한시적으로 비교한다. 마이크로 읽은 자기소개, 회의 전에 공개된 명부, 바로 이어진 두 음성 구간이 맞으면 실명 후보를 표시한다. 짧은 동의 표현, 겹침, 수집 중단, 재연결, 시각 역전에서는 연결을 끊는다. 모델은 수집기에서 실행한다. 매번 새 수집 세션을 만들고 게시 요청에는 정책 이름, 세션과 근거 자막 ID를 넣는다. Worker는 해당 회의의 원문과 명부로 매번 판정하고 회의록을 다시 열 때도 같은 근거를 확인한다.

본회의 자유발언 설정은 의장의 명시적 호명, 같은 사람의 자기소개, 초기 후속 발언의 음성을 각각 확보한다. 이후 문장은 그 회의에서 얻은 두 기준 음성과 모두 대조하고 의장의 음성과도 구별한다. 시간이 흐르거나 질문·교대·불명확한 음성이 끼면 후보를 보류한다. 한국어가 짧게 끊겨 이름이 잘못 들리는 사례 때문에 자동 후보는 화면과 내보내기 자료에서 추정으로 구분한다.

## 설정을 바꾸고 검증하기

본회의 음성 대조의 `podium` 설정은 Python 수집기와 JavaScript Worker가 같은 [정책 파일](../dist/speaker-policy.js)에서 읽는다. 호명은 최소 3.5초, 자기소개와 별도 확인은 각각 최소 2.5초, 후속 발언은 최소 3.5초다. 확인되지 않은 발언에 이름을 연장하는 한도와 음성 기준을 바꿨을 때는 원음을 다시 인식하고 서명된 Worker 입력까지 같은 조건으로 확인한다.

생중계 판정에 쓰는 시간과 최소 발언 길이는 [speaker-policy.js](../dist/speaker-policy.js)에 있다. `Seconds`는 영상 내 초, `Ms`는 수집 시각 기준 밀리초다. 직접 호명 뒤 발언은 5초, 연속 문장의 연장은 1.5초가 기본 상한이다. 질의자의 이름을 다시 쓸 수 있는 최대 시간은 자기소개 후 8분이며 그 안에서도 최근 명패 근거가 필요하다. 이 값들은 검증 가능한 운영 설정이며 측정된 영상·음성 동기화 오차를 뜻하지 않는다.

저장소 루트에서 Node.js 24로 실행한다. 같은 입력으로 이전 엔진을 비교하려면 이전 버전의 `dist` 디렉터리에 함께 있던 모듈을 유지한다.

```sh
node evaluation/speaker_harness.cjs
node evaluation/speaker_harness.cjs --baseline ../previous/dist/live-speaker.js
node evaluation/speaker_harness.cjs --fixture evaluation/speaker_cases.json --json
node --test "tools/test_*.cjs" "tools/test_*.mjs" "evaluation/*.test.cjs"
```

[사례 파일](../evaluation/speaker_cases.json)의 `expected_name: null`은 주어진 단서로 실명을 부여하면 안 된다는 뜻이다. 회의록에 실제 화자가 알려진 발언도 입력 자막에 단서가 없으면 이 기대값을 쓴다. 직책까지 검증하려면 `expected_role`을 추가한다. 이름을 기대하는 사례에서는 이름을 보류해도 실패한다. CI는 판정 불일치, 누락된 근거 ID, 출처와 다른 고정 VOD 자막을 검사한다.

오류를 추가할 때는 회의 ID, 자막 ID, 영상 시각, 직전·직후 발언, 이용 가능한 명패와 수집 중단을 함께 보존한다. 공식 화자 표기는 기대값이나 출처 설명에만 넣는다. 보고서에는 **실제로 이름을 붙인 수**와 **이름을 붙여야 했던 수**를 각각 분모로 제시한다. 원음 대조가 끝나지 않은 공개 자막과 구성 사례의 지표는 해당 정책을 재현하는 정도다. 현장 정확도를 평가할 때는 정책 조정에 쓰지 않은 날짜·위원회를 골라 독립적으로 원음을 듣고 화자와 교대 시점을 표시한다.

위원장이 대수·전후반기·위원회명·자기 이름과 선출 사실을 한 자막에서 밝히면, 선출 당일 등록된 의회 방송의 당선 인사 장과 대조한다. 회의와 자기소개 양쪽에서 위원회가 일치해야 한다. 출처 영상과 같은 날, 혼합 발화·명패 충돌, 중단·겹침이 있는 발언은 보류한다. 자막 ID와 이전 공식 영상 위치를 결과에 함께 남긴다. 호명과 자기소개에서 같은 철자의 이름이 반복돼도 두 자막의 인식 오류가 같을 수 있다. 짧은 간격으로 직접 보고를 청한 말과 본인이 밝힌 직책이 일치하면 ‘의회사무과장’, ‘주무관’ 등 직책을 표시할 수 있다. 이때 실명 칸은 비워 두고 근거가 된 두 자막 ID를 남긴다.

## 국·과장이 참석자를 소개할 때

“간부 공무원을 소개해 드리겠습니다”에 이어 국장이 이름과 직책을 차례로 읽으면 그 음성은 국장의 것이다. 같은 명단을 계속 읽는 동안에는 나열된 이름을 자막에 붙이거나 음성 대조의 기준으로 등록하지 않는다. 음성인식이 첫 마침표를 빠뜨리거나, 이름을 다음 줄에 적거나, 두 줄의 시각이 40밀리초 이내로 겹쳐도 이 구분을 적용한다. 진행자가 발언을 넘기고 당사자가 직접 소개하면 다시 대조한다. [환경보건국장 소속 간부 소개 및 자원순환과장 본인 인사](https://www.sncouncil.go.kr/record/recordView.do?key=71fb9429520b3f4baf879bde74eb957196ad683faccef39c57ddca76ae5a4d0a2b04dec4ea80bd97)

집행부에 발언을 청할 때 의장이 말한 부서·직책과 곧이어 당사자가 밝힌 부서·직책을 대조한다. 이전 공식 방송에서 해당 직위를 확인했어도 발언일에 그 사람이 재직했다는 근거가 부족하면 직책까지만 표시한다. 5418번 4분 34초에는 ‘교통기획과장’을 표시한다. [당일 원본](https://cast.sncouncil.go.kr/vod/vod_view.jsp?pk_vod_no=5418&position=266) · [4월 17일 건설교통국 방송](https://cast.sncouncil.go.kr/vod/vod_view.jsp?pk_vod_no=5389&position=3290)

## 청원 제안설명과 감사 선서

청원을 상정하면서 밝힌 의원 이름, 곧이은 직접 호명, 실제 설명자가 다시 말한 청원명을 대조한다. 고유한 지명·시설명 등이 같은 청원으로 이어져야 제안설명 줄에만 실명 후보를 표시한다. 같은 사람이 공식 의안을 발의했더라도 심의 중 다른 사람이 발언할 수 있다. 대리 설명, 주제 불일치, 교대나 수집 중단이 있으면 보류한다. [제312회 도시건설위원회](https://cast.sncouncil.go.kr/vod/vod_view.jsp?pk_vod_no=5418&position=586)

행정사무감사 선서에서는 직접 호명, 본인 선서의 시작과 끝, 당일 날짜·성남시·직책·이름으로 끝나는 서명 낭독을 각각 확인한다. 낭독한 이름과 직책이 발령일을 확인한 공식 명부와 일치하면 서명 줄에만 실명 후보를 표시한다. [11월 25일 푸른도시사업소 선서](https://cast.sncouncil.go.kr/vod/vod_view.jsp?pk_vod_no=5552&position=12233)

과장에게 “저한테 하신 말씀 그대로 … 장담할 수 있어요?”라고 물은 경우처럼 호칭과 질문 대상이 분명하면 ‘질의자’를 표시한다. 이름이 적힌 명패와 답변자 명패가 한 화면에 있고 화자 전환 근거가 부족하면 실명은 비워 둔다. [11월 23일 행정교육위원회](https://cast.sncouncil.go.kr/vod/vod_view.jsp?pk_vod_no=5547&position=6884)

개의·안건 상정·의결 선포를 직접 알리는 문장에는 **의사진행자** 역할을 쓴다. 이름이나 직책은 그 역할만으로 결정할 수 없다. 심사 경과 보고에서 과거 의결 결과를 낭독한 문장, 의결을 요청한 문장, 다른 참석자의 “없습니다” 답변이 같이 들어온 문장은 이 대상에서 제외한다.

다시보기에서 현재 문장만으로 이름을 특정하지 못해도, 바로 뒤 문장이 들어오면 앞줄을 다시 대조한다. 두 줄이 해당 영상의 공식 회의록에서 한 사람의 같은 발언 안에 순서대로 놓이고 뒷줄에 같은 공식 근거가 있을 때만 앞줄에 이름을 표시한다. “알았나요. 그렇습니다. 그렇더라면…”처럼 다른 사람의 짧은 대답이 끼면 보류한다. 보정이나 재생 위치 변경으로 근거가 바뀌면 이전 이름 표시도 다시 계산한다. [5479번 질의와 답변 원본](https://cast.sncouncil.go.kr/vod/vod_view.jsp?pk_vod_no=5479&position=1213)

당시 수집 회의록에 현행 발언자 정책이 적용됐다는 표시가 있으면, 다시보기에서도 그때의 명패와 위원 명부로 판단한 결과를 사용한다. 선서 서명 자막을 대조할 때는 날짜와 상투구가 여러 증인에게 반복될 수 있어 재생 중에 들린 직책 전체와 이름이 함께 일치해야 한다.

‘부탁드립니다’ 한마디가 독립 자막으로 들어온 경우에는 바로 앞 문장의 끝도 확인한다. 앞 자막만으로 같은 영상의 발언자를 찾을 수 있고, 앞의 마지막 15글자와 짧은 술어가 공식 회의록의 한 문장 안에 그대로 이어져야 한다. 재인식 초안에 감사 인사가 하나 더 들어간 경우에는 같은 공식 발언의 바로 다음 문장까지 대조한다. 앞 자막을 다시 인식한 결과가 달라지거나 재생 위치를 바꾸면 해당 이름도 다시 판단한다. [5478번 장정현 의원 발언](https://cast.sncouncil.go.kr/vod/vod_view.jsp?pk_vod_no=5478&position=1589)

브라우저에서 8초씩 끊은 연속 음성은 재생 시계를 따로 읽기 때문에 경계가 조금 겹쳐 보일 수 있다. 실제 재생에서 약 5.45밀리초를 관측했다. 짧은 술어를 대조할 때에 한해 같은 인식 세션에서 연속으로 수집된 두 조각은 최대 10밀리초까지 이어진 것으로 본다. 화면과 내려받는 파일에는 수집 시각을 그대로 쓴다.

회의록에서 같은 사람의 질문과 다음 발언 사이에 다른 사람의 짧은 답변이 있으면 질문과 재개 문장을 한 사람의 자막으로 합치지 않는다. 원음 인식 초안의 질문 끝 13글자와 이후 발언 첫 9글자가 같은 공식 기록의 각 위치에만 나타나고, 그 사이에 다른 이름으로 기록된 짧은 답변이 있을 때 적용한다. 5476번 23분 44초에 질문자와 의회사무과장 음성이 함께 잡히는 사례를 확인했다. [공식 원본 영상](https://cast.sncouncil.go.kr/vod/vod_view.jsp?pk_vod_no=5476&position=1424)

## 2026년 11월 25일 고정 자료 비교

기준 버전은 `ec94b2b`이다. 관찰 자막 12구간에서 실명을 기대한 5건 중 일치한 건수는 4건에서 5건으로, 실명을 보류해야 하는 7건에 이름을 붙인 건수는 2건에서 0건으로 바뀌었다. 구성한 경계 사례 18구간에서는 이름을 기대한 4건 모두 일치했고, 보류 대상 14건에서 실명을 부여한 사례는 없었다.

5483번 영상에서는 기존에 회의록과 대조한 자막 안에 보존돼 있던 ASR 원문 12개를 개인 자막 입력으로 재생했다. 이전 개인 자막 경로에서 실명을 낸 구간은 0개였다. 변경 후에는 7개에서 회의록 표기와 같은 실명을 냈고 5개에서 보류했다. 예를 들어 ASR의 ‘채민수’와 회의록의 ‘최민수’가 충돌한 자기소개는 보류했다. 같은 영상에 이미 정렬해 둔 구간을 쓴 회귀 검사다.

생중계의 별도 공개 스냅샷에서 자막 4,088개를 재생했다. 경제환경위 2,094개 중 실명 후보는 32개에서 12개로, 행정교육위 959개에서는 6개로 유지됐고 도시건설위 1,035개에서도 2개로 유지됐다. 한 명의 자기소개와 명패를 근거로 뒤의 여러 질문에 같은 이름을 이어 붙이던 경우가 줄었다. 세 회의의 실제 화자 정답은 독립적으로 청취·검수하지 않았다. 문화복지체육위는 조회 당시 누적 자막이 없어 제외했다.

실제 원음, 브라우저 임의 위치 재생, 서명과 미확인 사례는 [11월 26일 구간별 검증 결과](../evaluation/20261126_speaker_replay.md)에서 확인할 수 있다. 서브에이전트 역할과 모델 설정은 [프로젝트 작업 지침](../AGENTS.md)에 있다.
