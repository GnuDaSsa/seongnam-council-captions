# 성남시의회 영상 자막과 회의록 초안

성남시 공무원이 성남시의회 회의에서 소관 안건과 발언을 찾고, 원본 장면을 확인해 회의록 초안을 작성하는 업무용 웹 도구다. 자료 출처는 성남시의회 인터넷방송과 공개 회의록이다. ChatGPT Sites에 공개해 링크가 있는 누구나 이용할 수 있다. [사이트 열기](https://seongnam-council-desk.gnudas0923.chatgpt.site)

## 경제환경위원회 생중계

11월 25일 제315회 정례회 행정사무감사 제1일차의 공식 HTTPS 영상을 직접 재생한다. 데스크톱 Chrome에서 **이 방송 자막 켜기**를 누르면 현재 탭의 방송 음성을 기기에서 한국어로 전사한다. 첫 사용에는 모델 다운로드가 필요하며, 생성한 구간은 **한글 저장**으로 내려받는다. [성남시의회 공식 중계](https://cast.sncouncil.go.kr/live/flashPlayer.jsp?live_no=2853)

## 업무에 쓰는 방법

1. 회기·회의명이나 업무 키워드로 회의를 고른다. 회의 머리말에서 영상 범위와 자료의 성격을 확인한다.
2. 찾은 발언에서 원본 시각을 열고 이름·숫자·안건을 대조한다. 직접 수정한 내용은 현재 브라우저에 저장된다.
3. 교정한 자료를 한글 회의록 초안(HWPX), 텍스트 또는 자막(WebVTT)으로 내려받는다. 안건별 요약은 원문 인용과 구분하고, 외부 인용 시 확정 회의록을 확인한다.
4. 추가 회의는 운영 PC에서 처리한다. 공식 영상회의록이 게시된 회의는 제공된 원문을 먼저 쓰고, 녹음만 있는 회의는 프로젝트용 OpenAI 키로 전사할 수 있다. 만들어진 회의 JSON을 사이트에서 열어 같은 방식으로 검토한다. [운영자 도구 안내](tools/README.md)

## 첫 버전의 구성

| 역할 | 기술 | 처리 내용 |
| --- | --- | --- |
| 회의 자료 수집 | Python, 공개 회의 목록, 공식 영상 링크 | 회기·차수·위원회·일자·안건·영상 ID를 기록한다. 담당자가 회의록 원문과의 연결을 확인한다. |
| 자막 제작 | FFmpeg, Python 3.11, faster-whisper | 운영 PC에서 회의당 한 번 음성을 전사하고 원본 기준 시작·끝 시각을 보존한다. |
| 교정·문서 생성 | 구간별 JSON, WebVTT, TXT, HWPX | 발언자·오인식·숫자를 확인한다. 같은 교정본에서 자막과 발언 순서별 회의록 초안을 생성한다. |
| 담당자 열람 | ChatGPT Sites, HTML·CSS·JavaScript | 회의 목록과 자막 파일을 제공한다. 브라우저에서 발언 검색, 원본 시각 이동, 파일 다운로드를 처리한다. |
| 소스 관리 | GitHub | 제작 도구와 사이트 소스를 관리한다. 첫 단계에서는 선별한 회의를 Sites에 배포할 때 검수한 결과를 함께 반영한다. |

운영자가 회의당 한 번 생성한 자료를 사용한다. 사이트 열람·검색·문서 다운로드에는 API 키가 필요 없다. OpenAI를 사용할 때는 운영 PC의 환경변수 `OPENAI_API_KEY`에서 읽는다. 키나 내부 업무 자료는 GitHub에 올리지 않는다. 프로젝트에는 공개 자료를 바탕으로 만든 시범 데이터만 포함한다.

## 성남 원본에서 확인한 사항

- 제315회 정례회 개회식 및 제1차 본회의 영상 ID는 5544다. 의회가 제공하는 페이지에서 회기·일자·진행순서를 확인했다. 이 영상의 발언자 정보는 비어 있어 음성만으로 의원 실명을 단정할 수 없다. [원본 영상](https://cast.sncouncil.go.kr/vod/vod_view.jsp?pk_vod_no=5544&position=700) · [영상회의록 검색](https://cast.sncouncil.go.kr/search/search_list.jsp)
- 이 원본 페이지는 HTTP 응답에 `X-Frame-Options: SAMEORIGIN`을 보낸다. 외부 사이트에서는 기본 동작을 '원본에서 이 발언 듣기'로 둔다. 위 예시에서 `position=700`은 11분 40초를 지정하며, 브라우저에서 시작 위치와 영상 길이 메타데이터를 확인했다. 여러 기기에서 소리까지 정상 재생되는지는 별도 검증 항목이다.
- 같은 영상의 HLS 재생목록은 확인했다. 공식 플레이어 연결 방식이 바뀔 수 있으므로 원본 주소와 수집 일시를 남긴다. 사이트 내 직접 재생이나 영상 클립 배포가 필요해지면 영상별 제공 조건과 지원 방식을 확인한다.
- 임베드가 허용된 공식 유튜브 영상은 IFrame Player API로 재생하고 `seekTo`로 발언 시각에 이동할 수 있다. 이 용도에는 YouTube Data API 키가 필요 없다. 공식 자막 파일을 받는 `captions.download`는 OAuth와 해당 영상 편집 권한이 필요하다. [YouTube 재생 API](https://developers.google.com/youtube/iframe_api_reference) · [자막 다운로드 API](https://developers.google.com/youtube/data/reference/rest/v3/captions/download)
- 확정 회의록은 성남시의회에서 공개한다. 국회도서관 지방의정포털도 인증키 기반으로 지방의회 회의록 목록과 본문을 제공한다. 성남 회의록의 수록 시차와 영상 ID와의 대응은 아직 측정하지 않았다. [성남시의회 회의록](https://www.sncouncil.go.kr/kr/assembly/late.do) · [국회도서관 Open API](https://clik.nanet.go.kr/potal/guide/resourceCenter.do)

## 전사 성능과 회의록 품질

로컬 시제품의 한국어 Whisper tiny 모델(CPU int8, beam size 5)로 위 본회의의 **20.02초** 구간을 재전사했다. 한 번의 측정에서 모델 준비에 **0.26초**, 전사에 **0.69초**가 걸렸고 시간 구간 **5개**가 나왔다. 짧은 발췌 한 건의 결과이며, 지명·사업명 오인식이 관찰됐다. 회의 전체의 처리 시간, 화자 구분, 실시간 지연은 이 수치로 판단할 수 없다. [faster-whisper](https://github.com/SYSTRAN/faster-whisper)

파일 전사는 이미 시작·끝 시각을 출력한다. 탭 음성 시제품은 브라우저에서 사용자가 공유를 허용한 오디오를 약 8초씩 받아 텍스트로 표시한다. 방송용으로 확장하려면 원본 시각과의 대응, 일시정지·탐색·연결 끊김, 재연결 후 중복·누락 처리가 필요하다. [브라우저 화면·소리 공유 규격](https://www.w3.org/TR/screen-capture/)

발언마다 회의 ID, 구간 ID, 원본 시작·끝 시각, 발언자, 전사 원문, 교정문, 검수 상태를 보관한다. 시간은 발췌 파일의 0초가 아니라 원본 영상 시작을 기준으로 저장한다. 발언자 미확인 구간은 그 상태로 표시한다. 초안에는 회의명·날짜·안건·발언·원본 링크·검수 상태를 넣고, 확정 회의록이 게시되면 별도 링크를 연결한다. 안건별 의결 결과와 자료 요구를 요약하는 기능은 근거 발언 구간을 함께 제시하도록 설계한다.

## 추가 기능에 필요한 API와 운영비

| 추가 기능 | 필요한 자원 | 도입 시점 |
| --- | --- | --- |
| 클라우드 파일 전사 | 운영 PC의 OpenAI API 키, 파일 전사 엔드포인트 | 공개 영상에 발언 원문이 없고 원본 녹음이 확보됐을 때 |
| 실시간 생자막 공유 | 방송 시간에 켜진 음성 수집·전사 작업자, 인증된 쓰기 API, 마지막 구간 이후를 읽는 조회 API | 회의 중 여러 담당자가 같은 자막을 보려 할 때 |
| 공동 교정·제보 | Sites Worker, D1, 편집자 인증과 권한, 수정 이력 | 담당자 여러 명이 교정 내용을 함께 반영할 때 |
| 문서·자막 파일 수시 갱신 | D1에 회의·구간, R2에 생성 파일 저장 | 재배포 없이 검수본을 반영할 때 |
| 안건별 AI 요약·질의응답 | 선택한 언어 모델 API, 근거 발언 조회, 서버 측 키와 이용 한도 | 초안의 근거 확인과 품질 평가를 마친 뒤 |

2026년 11월 25일 공개 단가 기준으로 OpenAI 파일 전사 `gpt-transcribe`는 분당 **US$0.0045**, 저지연 실시간 전사 `gpt-live-transcribe`는 분당 **US$0.017**이다. 3시간 회의 20회(3,600분)를 한 번씩 전사하면 각각 **US$16.20**, **US$61.20**이다. 두 방식은 별도 시나리오다. 요약, 재처리, 저장·전송, 호스팅 및 세금은 제외했다. 방문자 수가 늘어도 저장된 자막 열람은 전사를 다시 호출하지 않는다. [파일 전사 모델 가격](https://developers.openai.com/api/docs/models/gpt-transcribe?site_locale=en) · [실시간 전사 모델 가격](https://developers.openai.com/api/docs/models/gpt-live-transcribe)

## 개발 순서와 확인 기준

1. 본회의와 위원회를 포함한 실제 회의로 전사 품질을 비교한다. 인명·사업명·금액·표결 숫자 오류, 작업 시간, 담당자 교정 시간을 기록한다.
2. 검수 가능한 한 회의를 선정해 자막 검색, 원본 장면 연결, WebVTT·텍스트·HWPX 출력까지 연결한다. 다운로드 문서와 홈페이지가 같은 교정본을 사용하는지, 휴대폰에서도 지정 시각에 접근하는지 확인한다.
3. 시범 운영에서는 담당자가 소관 안건을 찾는 시간, 회의당 교정 시간, 회의록 초안 활용도를 확인한다. 직원 간 공유 대상은 Sites의 이용 권한으로 설정한다.
4. 생중계 수요가 있으면 운영 PC 한 대로 한 채널을 시범 중계한다. 동시 위원회 수, 지연과 중단 시 복구 시간을 측정해 전용 작업자나 클라우드 전사 도입을 결정한다.

광진구의 발언 인용·검수 흐름과 경기도의회의 공개 구현을 참고했다. 경기도의회 코드에는 기관별 인증과 영상관리 연계가 있으므로 성남 영상·회의록은 독립적으로 연결한다. [광진 AI 자막 ON](https://gj-ai-on.pubax.org/?about=1) · [경기도의회 공개 소스](https://github.com/gyeonggi-council/ai-live-transcribe)
